# Overview

This project can be viewed as a website here:
https://adamrossnelson.github.io/giving-help/

The purpose of this project is to provide an example research memo that may have been written by a first-time research memo author in a group or lab research setting. The student wrote the memo (with a few oversights or room for improvment outlined below).

Now the student is seeking feedback from peers. The student researcher (hypotehtically) goes to peers with this memo and asks for feedback.

# Opportunities for Improvement + Enhancement

Below are opportunities for improvement and enhancement that we would expect more experienced peer or near-peer reviewers to identify and suggest:

- Specfy the null and alternative hypotheses
- Answer the research question in the terms implied by the question
  - For a yes or no question give a yes or no response.
  - The first word of the answer should be a yes or no.
- Use Quarto's cross references to point specifically to the specific figure.
- Better elaborate on the data used (one sentence really).
- Triangulate results with additional analyses or methods
  - Add a regression analysis
  - Add a correlation analysis
